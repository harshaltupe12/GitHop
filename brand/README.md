# GitHop brand kit

The GitHop logo is a **rising loop**: a line that loops (switching identity) and then climbs up to the top right (moving forward). The primary app icon is the **light tile** version: ink loop and aqua arrowhead on a white rounded tile.

Open [index.html](index.html) in a browser to see every asset on one page.

## Using it in the app (Tauri)

Generate every Tauri icon from the 1024 px master:

```bash
cd app && npx tauri icon ../brand/png/icon-light/githop-icon-light-1024.png
```

This writes `app/src-tauri/icons/` (including `icon.ico`). Small sizes come out sharper if you then replace `icon.ico` with `brand/ico/githop.ico`, which uses the heavier favicon geometry at 32 px and below.

The **tray icon is not the logo.** It shows the default profile's colour dot ([Design §6.2](../Design.md#62-tray-icon-system-tray-16202432-px-ico)). The logo appears in the tray only for the "setup needed" and error states.

## Rules

- **Clear space:** keep empty space of at least ¼ of the icon's width on every side (16 px around a 64 px icon).
- **Minimum size:** icon 16 px (use the favicon variant at 32 px and below); horizontal lockup 24 px tall.
- **Backgrounds:** use the light tile or the colour mark on light backgrounds, and the dark tile or the reverse mark on dark backgrounds. On photos or busy backgrounds, always use a tile.
- **Don't:** recolour the loop or arrow outside these variants, use vermillion or sunshine (they mean "blocked" and "warning" in the app), stretch or rotate the mark, add shadows, gradients or outlines, or set the wordmark in any font other than IBM Plex Sans SemiBold.

## Typeface

The wordmark is IBM Plex Sans SemiBold (600), letter-spacing −0.02em. The font is **embedded** in the wordmark, lockup and graphics SVGs (SIL Open Font License 1.1), so they render correctly anywhere. For print or design tools that ignore embedded fonts, convert the text to outlines.

## Regenerating

The kit is generated by code, so it stays consistent:

```bash
python brand/tools/make_brand.py .     # writes all SVGs (needs app/ui/node_modules for the font)
python brand/tools/render_png.py .     # writes PNG + ICO (needs Pillow + Playwright's headless Chromium)
```

Change the shapes or colours in `make_brand.py`, never by hand-editing the outputs.
